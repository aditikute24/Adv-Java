# 02-GenericServlet

## Description
This project demonstrates the use of **GenericServlet** in Java Servlet technology.  
It takes user input from an HTML form and processes the request using a GenericServlet class.

## Technologies Used
- Java
- Servlet API
- GenericServlet
- HTML
- Apache Tomcat Server
- Eclipse IDE

## Project Structure

```
02-GenericServlet

├── src

│       │

│           ├── index.html
│           └── WEB-INF
│               └── web.xml
│
└── pom.xml
    └── Maven dependencies configuration
```
## How to Run the Project

1. Open the project in Eclipse IDE.
2. Configure Apache Tomcat Server.
3. Run the project on the server.
4. Open the browser and enter the required URL.
5. Submit the form to see the servlet response.

## Features
- Accepts user input through HTML form.
- Uses GenericServlet to handle HTTP requests.
- Displays processed response.
